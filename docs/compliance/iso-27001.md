# ISO/IEC 27001:2022 — Information Security Management System Mapping

> **Standard:** ISO/IEC 27001:2022 (3rd edition, October 2022)  
> **COBIT alignment:** APO13 (Managed Security), DSS05 (Managed Security Services), MEA03 (Managed Compliance)  
> **Applicability:** All systems within the health data architecture pipeline

---

## Overview

ISO/IEC 27001:2022 specifies the requirements for establishing, implementing, maintaining, and continually improving an Information Security Management System (ISMS). The 2022 edition restructured Annex A from 114 controls (2013) to 93 controls across four themes.

---

## ISMS Scope Statement

**Applicable to:** All information systems that process, store, or transmit electronic protected health information (ePHI) within the health data architecture pipeline, including:
- EHR system interfaces and integration engines
- Operational and research data warehouses
- Common data model environments (OMOP, PCORNet, i2b2)
- De-identification processing environments
- External collaboration and federated query platforms

**Exclusions:** Personal workstations used exclusively for de-identified data analysis (no direct PHI access) may be scoped out with documented justification.
