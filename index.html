Branch Strategy

Production-grade workflow

5 protected branches with automated status checks — every change to main must pass PHI scanning, Mermaid validation, and DCO sign-off.

Branch Purpose Protection CI Gates
main Production documentation 🔒 Full — 1 reviewer + CI Lint, PHI, Mermaid, DCO
develop Active development 🔒 Full — 1 reviewer + CI Lint, PHI scan
staging Pre-production review 🔒 Full — 1 reviewer + CI Lint, PHI, Mermaid
baseline Compliance snapshot (v1.0.0) 🔒 PR required No force-push or deletion
prototype Experimental features 🔑 Light — no force-push No deletion
